# Real certificate image paths

This is a **code-only update**. No certificate images are included or modified.

Copy the `src` directory into the root of your existing `my-portfolio` project.

Place your actual images inside `public/certificates/` and name them:

- `responsive-web-design.jpg`
- `isite-quiz-bee.jpg`

If your genuine images use different file names or `.png` formats, keep your existing images as they are and instead edit the `image` values in `src/data/portfolio.ts` to match. Filename casing matters on Vercel.

The achievements gallery no longer refers to the images as samples. Other project image examples are intentionally unchanged.

Run `npm run build` before committing your changes.
